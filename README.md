# Volta Digital Skills Academy: Student Registration

A Windows Forms application written in Visual Basic (.NET) that registers new students for **Volta Digital Skills Academy (VDSA)**. It replaces the paper notebook the academy used, where names were misspelt and fees were worked out wrongly.

## Features

- **Registration form** that collects the student's surname, other names, date of birth, gender, phone number, email, Ghana Card number, region, passport photo, programme, modules, number of months, start date, payment mode, number of instalments and amount paid.
- **Automatic age** shown as soon as a date of birth is chosen.
- **Module list with prices.** The ticked modules and their prices are shown in a separate list.
- **Instalments box** that can be changed only when *Instalment* payment is selected.
- **Progress bar** that moves as the form is filled.
- **Tooltips** on the main controls, and a **Terms and Conditions** link.
- **Fee calculator** that shows tuition, discount, service charge, total fee, balance and each instalment, both on the form and in a fee breakdown list.
- **Validation** that refuses a wrong form and tells the user exactly what to fix.
- **Printed-style receipt** with bold headings, the total fee in blue and the balance in red.
- **Status bar message** confirming a successful registration.
- **Clear** and **Exit** buttons.

## Fee rules

Monthly prices (GHC):

| Module | Price per month |
| --- | --- |
| MS Office | 120 |
| Web Design | 200 |
| Graphic Design | 180 |
| VB Programming | 250 |
| Networking | 150 |

The registration fee is **GHC 50**.

| Item | How it is calculated |
| --- | --- |
| Tuition | total price of the ticked modules x number of months |
| Discount | tuition x discount rate. The rate is 10% if the months are 6 or more, plus 5% if the student pays in full |
| Service charge | (tuition - discount) x 2.5% |
| Total fee | (tuition - discount) + registration fee + service charge |
| Balance | total fee - amount paid |
| Each instalment | balance / number of instalments (Instalment mode only) |

All amounts are rounded to 2 decimal places.

## Validation rules

The **Register** button does not accept the form, and lists the problems, if:

1. a name is empty or contains digits;
2. the student is under 15;
3. the phone number or Ghana Card number is not complete;
4. the email has no `@`;
5. gender, region, programme or a module is not chosen;
6. the amount paid is not a number or is more than the total fee;
7. the Terms and Conditions box is not ticked.

## Getting started

### Requirements

- Windows
- A recent version of Visual Studio with the **.NET desktop development** workload installed

### Run the project

1. Clone the repository:

   ```bash
   git clone https://github.com/edemkudjoe/Volta-Digital-Skills-Academy-Student-Registeration-Group-Work-.git
   ```

2. Open `Group Work.slnx` in Visual Studio. (If your version of Visual Studio cannot open `.slnx` files, open `Group Work.vbproj` instead.)
3. Press **F5** to build and run.

## How to use the program

1. Fill in the personal details, then choose the programme and tick the modules.
2. Choose the number of months, the start date and the payment mode. For *Instalment*, set the number of instalments.
3. Type the amount paid and click **Calculate** to see the fees.
4. Tick the Terms and Conditions box and click **Register**. If anything is wrong, a message lists what to fix. Otherwise the receipt appears and the status bar confirms the registration.
5. Click **Clear** to start a new student, or **Exit** to close the program.
